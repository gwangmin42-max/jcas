# JW Customs Audit System (J-CAS)

관세성실신고 확인제도 검증 프로그램

UNI-PASS 수입신고 내역(란 단위) 엑셀을 올리면 성실신고 확인 때 관세사가 다시 볼 의심 건을 찾아 주는 로컬 프로그램입니다.
파일은 이 컴퓨터에서만 처리되고 저장되지 않습니다. (외부에 배포하지 마세요: 업체 자료를 다룹니다)

## 실행
```
npm install
npm run dev      # http://localhost:3000
```
명령줄로 바로 확인하려면: `npm run check -- "엑셀경로"`

## 검증 항목 (lib/verify.ts)
| 분야 | 검사 |
|---|---|
| 품목분류 | 같은 품명이 서로 다른 세번으로 신고된 건 (4단위부터 다르면 "높음") |
| 세율·세액 | 같은 세번·원산지·세율구분인데 적용세율이 다른 건 / 과세가격 × 세율 ≠ 신고 관세액 |
| FTA·원산지 | FTA 세율인데 원산지증명 없음 / FTA 상대국과 원산지 불일치 / 같은 품목의 FTA·일반세율 혼재 / 발급번호 누락(열이 채워진 파일만) |
| 과세가격 | FOB 등인데 운임 0 / 같은 품목 단가가 중앙값의 3배 이상·1/3 이하 (수량이 있는 란만) |

결과는 "오류 확정"이 아니라 확인 대상입니다. 파일에 없는 열은 검사를 건너뛰고 리포트의 "수행하지 못한 검사"에 적습니다.

## 아직 안 한 것
- PDF 리포트 (엑셀만 지원)
- 수입요건(세관장확인) 누락 검사: 요건 대상 HS코드 목록이 필요
- HS코드별 기준 세율표와의 대조: 외부 기준 데이터가 필요
